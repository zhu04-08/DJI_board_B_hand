# 无人机载反射光谱采集

## 硬件配置与 GPIO 映射

### 主控芯片：ESP32-S3 (N16R8)
### 拓展芯片：SC16IS752IPW SPI2_HOST引脚配置：
|SC16IS752硬件|ESP32 S3引脚|参数|
|:---:|:---:|:---:|
|SCLK|GPIO 12|
|MOSI|GPIO 11|
|MISO|GPIO 13|
|CS|GPIO 10|
|IRQ|GPIO 14|
|RST|GPIO 9|
|晶振频率||1.8432 MHz|
|目标波特率||115200 bps|

warning：在1.8432MHz情况下，最高支持115200bit/s数据传输，一帧约4000字节情况下，每秒约3帧，若提升至14.7456MHz，可使用230400bit/s，每秒约6帧

SPI最大时钟为4Mbit/s，每路uart速率限制在2000000bit/s以内即可
### 拓展存储：TF卡 SPI3_HOST配置:
|TF卡硬件|ESP32 S3引脚|
|:---:|:---:|
|CS|GPIO 5|
|MOSI|GPIO 7|
|CLK|GPIO 6|
|MISO|GPIO 4|
### 拓展4G芯片：ML307 UART_NUM_2配置：
|ML307硬件|ESP32 S3引脚|
|:---:|:---:|
|ML307_TX_PORT|GPIO 17|
|ML307_RX_PORT|GPIO 18|
### 通信：A板 UART_NUM_1配置：
|A板硬件|ESP32 S3引脚|
|:---:|:---:|
|BoardA_TX|GPIO 35|
|BoardB_RX|GPIO 36|

## 软件配置
### microsd存储格式
|序号|字段名称|数据类型|字节数|说明|
|---|---|---|---|---|
|1|时间戳|`uint32_t`|4|UTC 秒（Unix 时间戳）|
|2|帧序号|`uint32_t`|4|采集帧编号，每采集一帧自增|
|3|数据来源|`uint32_t`|4|“A”表示A通道采集，"B"表示B通道采集|
|4|纬度|`int32_t`|4|纬度，**单位 1e-7 度**，北纬为正|
|5|经度|`int32_t`|4|经度，**单位 1e-7 度**，东经为正|
|6|高度|`int32_t`|4|相对起飞点高度，**毫米**|
|7|起始波长|`uint16_t`|2|光谱起始波长，**纳米**|
|7|终止波长|`uint16_t`|2|光谱终止波长，**纳米**|
|8|曝光状态|`uint8_t`|1|0x00--正常；0x01--过曝；0x02--欠曝|
|9|曝光时间|`uint32_t`|4|曝光时长，**微秒**，低位在前，高位在后|
|10|光度学参数|`float[47]`|188|47 个光度学参数，每个值的具体含义，见表 1 光度学参数说明|
|11|蓝光危害参数|`float`|4|1 个参数 Eb，见表 2 参数说明|
|12|近红外参数|`float[3]`|12|3 个参数，每个值的具体含义，见表 3 参数说明|
|13|植物光照参数|`float[16]`|64|16 个参数，每个值的具体含义，见表 4 参数说明|
|14|光谱系数|`int16_t`|2|光谱系数 N 表示光谱数据比实际值放大了 10 的 N 次幂|
|15|光谱数据|`uint16_t[]`|2*N|1 个数据占 2 个字节，低位在前，高位在后，数据个数取决于光谱输出频段|
